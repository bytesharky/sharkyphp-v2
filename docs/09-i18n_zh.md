# 多语言 I18n

`Sharky\Support\I18n` 提供语言协商与翻译能力，基于「语言文件目录 + 可用语言列表 + 默认语言」工作。

## 语言文件

每个语言一个 PHP 文件，返回键值数组，文件名即语言 tag：

```php
// languages/zh.php
return [
    'welcome' => '欢迎，:name',
    'bye'     => '再见',
];

// languages/en.php
return [
    'welcome' => 'Welcome, :name',
    'bye'     => 'Goodbye',
];
```

占位符 `:key` 会被 `trans()` 的变量替换。

## 实例化与翻译

```php
use Sharky\Support\I18n;

$i18n = new I18n(
    base_path('languages'),   // 语言根目录
    ['zh', 'en', 'jp', 'kr'], // 期望启用的语言（仅真实存在的文件才生效）
    'en'                      // 默认/回退语言
);

$i18n->negotiate(['zh' => 1.0, 'en' => 0.9]);   // 按 Accept-Language 协商
$i18n->setLang('zh');                           // 手动指定语言
$i18n->getLang();                               // 当前语言

echo $i18n->trans('welcome', ['name' => 'Tom']); // 当前语言翻译，缺失回退默认语言
```

- `negotiate(array $acceptParsed)`：`$acceptParsed` 为 `语言tag => 权重` 的数组（可用 `I18n::parseAcceptHeader()` 从请求头解析）。
- `trans($key, array $vars = [])`：翻译；找不到当前语言时回退到默认语言；都找不到则返回原 key。
- `I18n::scanDir($root)`：扫描目录自动发现语言文件，返回 tag 列表。
- `I18n::parseAcceptHeader($header)`：解析 `Accept-Language` 字符串为 `tag => q` 数组。

## 通过容器注入（推荐）

在 `configs/service.php` 中绑定为共享服务，控制器里 `Container::get(I18n::class)` 即可使用：

```php
// configs/service.php
return [
    'bindings' => [
        \Sharky\Support\I18n::class => [
            'concrete' => static function () {
                $path = \Sharky\Support\Helper::base_path('languages');
                return new \Sharky\Support\I18n($path, \Sharky\Support\I18n::scanDir($path), 'en');
            },
            'shared' => true,
        ],
    ],
    'listeners' => [],
];
```

```php
use Sharky\Facade\Container;
use Sharky\Support\I18n;

$i18n = Container::get(I18n::class);
echo $i18n->trans('welcome', ['name' => 'Tom']);
```

示例项目中的基础控制器即采用这种方式，并注册了模板函数 `__()` 供模板调用。
