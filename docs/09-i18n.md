# Internationalization (I18n)

`Sharky\Support\I18n` provides language negotiation and translation capabilities, working on the basis of a "language file directory + list of available languages + default language".

## Language Files

One PHP file per language, returning a key-value array; the file name is the language tag:

```php
// languages/zh.php
return [
    'welcome' => '欢迎，:name',
    'bye'     => '再见',
];

// languages/en.php
return [
    'welcome' => 'Welcome, :name',
    'bye'     => 'Goodbye',
];
```

The `:key` placeholder is replaced by the variables passed to `trans()`.

## Instantiation and Translation

```php
use Sharky\Support\I18n;

$i18n = new I18n(
    base_path('languages'),   // language root directory
    ['zh', 'en', 'jp', 'kr'], // languages to enable (only files that actually exist take effect)
    'en'                      // default / fallback language
);

$i18n->negotiate(['zh' => 1.0, 'en' => 0.9]);   // negotiate by Accept-Language
$i18n->setLang('zh');                           // manually specify a language
$i18n->getLang();                               // current language

echo $i18n->trans('welcome', ['name' => 'Tom']); // translate in the current language, fall back to default if missing
```

- `negotiate(array $acceptParsed)`: `$acceptParsed` is an array of `language tag => weight` (you can use `I18n::parseAcceptHeader()` to parse it from the request header).
- `trans($key, array $vars = [])`: translates; falls back to the default language when the current language is not found; returns the original key if neither is found.
- `I18n::scanDir($root)`: scans a directory to auto-discover language files and returns the list of tags.
- `I18n::parseAcceptHeader($header)`: parses an `Accept-Language` string into a `tag => q` array.

## Injection via the Container (Recommended)

Bind it as a shared service in `configs/service.php`, then use `Container::get(I18n::class)` inside the controller:

```php
// configs/service.php
return [
    'bindings' => [
        \Sharky\Support\I18n::class => [
            'concrete' => static function () {
                $path = \Sharky\Support\Helper::base_path('languages');
                return new \Sharky\Support\I18n($path, \Sharky\Support\I18n::scanDir($path), 'en');
            },
            'shared' => true,
        ],
    ],
    'listeners' => [],
];
```

```php
use Sharky\Facade\Container;
use Sharky\Support\I18n;

$i18n = Container::get(I18n::class);
echo $i18n->trans('welcome', ['name' => 'Tom']);
```

The base controller in the example project uses this approach, and registers the `__()` template function for use inside templates.
